# Silent 60-second demo

Open `index.html` in a browser and record the browser window. The demo advances automatically every 8 seconds and loops.

## Recording

- Use a 16:9 browser window.
- Hide bookmarks and unrelated tabs.
- Start recording on the first frame.
- No microphone or voiceover is needed; the bottom caption is the transcript.
- Stop after the final GitHub URL frame.
- Arrow keys can move backward/forward during rehearsal.

## Story

The demo shows why production agent evaluation must score the execution trajectory as well as the final answer. The failure transcript is intentionally illustrative; it does not claim to be a live-provider benchmark. All bundled project data remains synthetic.
